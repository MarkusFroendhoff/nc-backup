Sicherungspunkt

            
Zuerst einen Sicherungspunkt wählen. Er gilt für das Holen einer einzelnen Datei und für die komplette Wiederherstellung.

            
            
    
          
    

          
    
            
    Einzelne Datei holen
    
            
    Die laufende Nextcloud bleibt unberührt. Die Datei landet in einem Export-Ordner auf diesem Server (unter /var/lib/nc-backup/exports). Von dort können Sie sie herunterladen, per SCP kopieren und selbst in Nextcloud hochladen.
    
            
    So finden Sie Fotos: Sicherungspunkt wählen, in das Datenverzeichnis wechseln, den Benutzerordner öffnen, dann files und z. B. Photos. Oder den Dateinamen suchen.
